**آموزش نتلیفای متود جدید**
***1⃣***
  برید تو سایت زیر  یک دامنه رایگان بگیرین
[https://dash.domain.digitalplat.org/signup?ref=RDPnPBCWbA](https://dash.domain.digitalplat.org/signup?ref=RDPnPBCWbA)
**اگر دامنه دارید نیازی نیست بخرید !**
• پیش دامنه 
.dpdns.org
رو انتخاب کنین ، بعضیا پولین
• فقط ایمیل درست بزنید بقیه مشخصات رو میتونید فیک بزنید بهتون یک دامین میده
• و اگه به گیتهاب وصل کنید و به پروژه اشون ستاره بزنین یک دامین دیگه هم میده 
***2⃣***
 بعد که ساختین باید برید توی کلودفلر 
• دامنه ک ساختین رو ثبت کنین و نیم سرور هارو ببرین تو سایت ک دامنه رایگان گرفتی ثبت کن
• بعد حالا توی کلودفلر باید یک رکود بزنین
Type: بذار روی CNAME
Name: بنویس a که بشه همان ساب دامین یا هر مقدار که دوست دارید !
مثلا
[a.be.dpdns.org](http://a.be.dpdns.org/)
Target: اون آدرس نت‌لیفای که پروژه کردی رو اینجا پیست کن (مثلاً 
[my-awesome-site.netlify.app](http://my-awesome-site.netlify.app/)
).
Proxy status: تیک ابر رو خاموش کن (خاکستری بشه).
دکمه Save رو بزن.
***3⃣***
 بعد برید وارد سایت نتلیفای بشین رو همون پروژه اتون کلیک کنید
• بعد بزنید Project navigation
• سپسDomain management بزنید روی Add a domain کلیک کنید
• و Add a domain you already own رو انتخاب کنید
• بعد ساب دامین ک ساختین رو وارد کنید و روی Verify کلیک کنید
• و سپس Add subdomain کلیک کنید
با این کار بدون شکن میتونید وصل بشید و مشکل اتصال و قطعی زیاد به دلیل کرم ریزی وزارت قطع ارتباطات را نخواهید داشت !
تموم چند دقیقه صبر کنید ثبت میشه 
موفق و موید باشین
[@IR_NETLIFY](https://t.me/IR_NETLIFY)
