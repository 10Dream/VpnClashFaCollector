نحوه راه‌اندازی dnstt روی سرور شخصی
در طول آموزش از مقادیر زیر به عنوان دامنه و ip استفاده میشه که باید با دامنه و ip خودتون جایگزین کنید.
Domain: 
[tunnel-lab.dev](http://tunnel-lab.dev/)
IP: 
[203.0.113.10](http://203.0.113.10/)
برای سرور هر سروری که داخل ایران نباشه کفایت می‌کنه و لوکیشن هم اهمیتی نداره. اگر سرور ندارید ارزون ترین سرور ممکن رو بگیرید.  دامنه هم ترجیحا ir نباشه یا از دامنه‌های رایگان  استفاده نکنید.
۱- داخل کلادفلر یا هر پنلی که برای مدیریت دامنه استفاده می‌کنید، دو رکورد باید تنظیم بشه.
یک رکورد از نوع A به اسم srv و مقدارش به آی‌پی سرورتون باید برسه. تیک پروکسی هم خاموش کنید.
Type: A

[203.0.113.10](http://203.0.113.10/)
Proxy: DNS Only (grey cloud)

[srv.tunnel-lab.dev](http://srv.tunnel-lab.dev/)
 → 
[203.0.113.10](http://203.0.113.10/)
رکورد 
[srv.tunnel-lab.dev](http://srv.tunnel-lab.dev/)
 یا ساب‌دامنه srv باید به ip سرورتون برسه.
رکورد دوم از نوع NS هست و یک ساب‌دامنه یک یا نهایت دو حرفی انتخاب کنید. اسم رو برای مثال بزارید x و مقدار هم به 
[srv.tunnel-lab.dev](http://srv.tunnel-lab.dev/)
 وصل میشه.
Type: NS
Name: x
Target: 
[srv.tunnel-lab.dev](http://srv.tunnel-lab.dev/)
Proxy: DNS Only
در صورتی که بار اول باشه که وارد پنل دامنه شدین و رکورد‌ها رو تنظیم کردین ممکنه تا ۴۸ ساعت هم طول بکشه تا بشینه.
