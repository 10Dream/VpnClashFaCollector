### 🕒 2026-11-11 13:50:00 UTC
**📌دسترسی رایگان به 100 میلیون توکن از چند مدل**
:
پلتفرم Dahl امکان استفاده از چند مدل هوش مصنوعی رو از طریق API فراهم کرده. طبق اعلام این سرویس، کاربران جدید میتونن 100 میلیون توکن رایگان دریافت کنن، بدون نیاز به ایمیل یا کارت بانکی.
***🔹***
 مدل‌های قابل دسترسی :
- MiniMax M2.7
- GLM 5.3 Flash
- DeepSeek V4 Flash
***🔸***
 نحوه دریافت و اتصال:
***1⃣***
 وارد سایت 
[https://inference.dahl.global](https://inference.dahl.global/)
 بشید و با انتخاب یک یوزرنیم ثبت‌نام کنید.
***2⃣***
 یک کد 32 کاراکتری بهتون نمایش داده میشه که در واقع رمز ورود به حساب شماست، حتما اون رو ذخیره کنید، چون امکان بازیابی مجددش وجود نداره.
***3⃣***
 از بخش API Keys، مقداری از موجودی توکن حساب (Pool) رو به API Key خودتون منتقل کنید.
***🔗***
 Base URL :
`https://inference.dahl.global/v1`
***⚠️***
 100 میلیون توکن، اعتبار مشترک برای استفاده از مدل‌هاست، نه سهمیه جداگانه برای هر مدل. این اعتبار یکباره هست و در صورت 7 روز عدم استفاده متوالی، منقضی میشه.
