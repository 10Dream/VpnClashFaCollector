**دسترسی به چند مدل در پلتفرم Aerolink**
 :
پلتفرم Aerolink امکان استفاده از مدل‌هایی مثل GPT-6.1 Sol و GPT-6 Luna رو از طریق API فراهم میکنه. طبق معرفی این سرویس، 7 مدل رایگان در دسترسه و کاربران جدید میتونن تا 5 دلار کردیت رایگان دریافت کنن.
***🔗***
 ثبت‌نام :
[https://aerolink.lat/register](https://aerolink.lat/register)
***🛠***
 نحوه دسترسی :
***1⃣***
در سایت ثبت‌نام کنید و API Key بگیرید.
***2⃣***
در ابزار یا کلاینت سازگار با API، بخش تنظیمات مدل یا Custom Endpoint را باز کنید.
***3⃣***
آدرس Base URL رو وارد کنید:
`https://cgapi.aerolink.lat/v1`
***4⃣***
حالت API را روی Chat Completions تنظیم کنید، کلید API رو وارد کنید و مدل مورد نظرتون رو انتخاب کنید.
***⚠️***
 اطلاعات مهم و خصوصی رو در هیچ پلتفرم واسطی به اشتراک نگذارید و به‌هیچ‌وجه به خرید Api در پلتفرم‌های جدید فکر نکنید، این سرویس‌ها صرفا برای استفاده رایگان معرفی میشن.

**🌐 گوگل Genie 4 را معرفی کرد، ساخت جهان‌های تعاملی با هوش مصنوعی**
!
گوگل دیپ‌مایند از Genie 4، نسل جدید World Model رونمایی کرد. مدلی که به‌ جای تولید یک ویدیوی از پیش‌ساخته، محیطی پویا می‌سازه که میشه درش حرکت کرد و با دستور متنی تغییرش داد. کاربردش ساخت نمونه‌های اولیه بازی، پیش‌ نمایش صحنه‌های فیلم، تولید تجربه‌های تعاملی و ایجاد محیط‌های شبیه‌سازی برای آموزش ربات‌ها و عامل‌های هوشمنده.
***🔹***
چه قابلیت‌هایی داره؟
-ساخت محیط‌های واقع‌گرایانه با حرکت و جزئیات بصری پیشرفته
-گشت‌وگذار و کنترل دوربین با کیبورد
 -تغییر محیط با دستور متنی، از تغییر آب‌وهوا تا اضافه‌ کردن شخصیت و اشیای جدید
-تولید همزمان صدای محیط، موسیقی و مکالمه شخصیت‌ها
●این مدل از Gemini Omni برای بازنمایی ظاهری و رفتار محیط و از سایر مدل‌های Gemini برای استدلال و حفظ پیوستگی اتفاقات کمک می‌گیرد.
