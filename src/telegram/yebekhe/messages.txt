### 🕒 2026-04-10 17:20:12 UTC
**تنظیم PyPi Mirror 🚀**
**معرفی PyPI**
مخزن 
**PyPI**
 یا Python Package Index مخزنی نرم‌افزاری برای زبان برنامه‌نویسی پایتون است. 
***🐍***
توسعه‌دهندگان پایتون می‌توانند:
• کتابخانه‌هایی که پیش‌تر توسط دیگران توسعه داده شده را از این مخزن دریافت کنند 
***📥***
• کتابخانه‌های خودشان را در این مخزن بارگذاری کنند تا دیگران هم از آن استفاده کنند 
***📤***
**نصب پکیج با Mirror در رانفلر**
اگه نمی‌خواید تنظیمات global انجام بدید، می‌تونید مستقیماً mirror رو در دستور نصب specify کنید: 
***⚙️***
pip install -i https://mirror-pypi.runflare.com/simple django
**تنظیم Mirror به صورت Global**
**لینوکس، مک و ویندوز**
 
***🖥️***
در ترمینال یا CMD دستورات زیر رو وارد کنید:
pip config --user set global.index https://mirror-pypi.runflare.com/simple
pip config --user set global.index-url https://mirror-pypi.runflare.com/simple
pip config --user set global.trusted-host mirror-pypi.runflare.com
حالا مثل همیشه می‌تونید نصب کنید: 
***✅***
pip install packageName
***✨***
 با این روش، پکیج‌ها از سرور داخل کشور رانفلر دانلود می‌شن و سرعت بهتری خواهید داشت! 
***🚀***
