***🗂️***
 تمام فایل های پروژه - findns — اسکنر DNS Resolver برای تانل
***🔥***
نسخه v0.1.5 — تغییرات:
قابلیت‌های جدید:
• دیتای آفلاین — ۷,۸۵۴ ریزالور شناخته‌شده ایرانی و ۱,۹۱۹ رنج CIDR داخل باینری embed شده، نیازی به دانلود رنج 
ها نیست
• دستور local با دو حالت:
  ◦ findns local -o resolvers.txt — خروجی ریزالورهای تأیید شده (نرخ موفقیت بالا)
  ◦ findns local -o candidates.txt --discover — تولید آی‌پی‌های کاندید از کل فضای آی‌پی ایران
• حالت‌های discover:
  ◦ --sample N — انتخاب تصادفی از هر سابنت (پیش‌فرض: ۱۰)
  ◦ --batch N --offset M — دسته‌بندی بدون تکرار
  ◦ --full — تمام ~11 میلیون آی‌پی
• fetch --local بروزرسانی شد — الان ۷,۸۰۰+ ریزالور شناخته‌شده رو merge می‌کنه (نه CIDR خام)
***📖***
 بخش readme و راهنمای فارسی (
[GUIDE.md](http://GUIDE.md/)
) به طور کامل بروزرسانی شدند — شامل توضیح کامل تمام دستورات، فلگ‌ها، مثال‌ها و سناریوهای کاربردی
***📎***

1- روی کانفیگ مد نظرشون که توی SlipNet اضافه کردن، ویرایش رو بزنن
2- اگر کانفیگ lock شده نیست، test domain رو دامنه‌ی کانفیگ بذارید، اگه هم که قفل هست بذارید 
[www.google.com](http://www.google.com/)
3- بقیه موارد رو دست نزنید اما Test URL (E2E) رو:
[https://www.google.com](https://www.google.com/)
بگذارید
4- محتویات داخل این فایل متنی رو import کنید
5- روی Start Simple Scan بزنید
6- بذارید کارش رو کنه، و از پایین Sort رو بذارید روی E2E و filter رو 4+ بذارید.
نکته: 4-5 بار این کار رو تکرار کنید، چون چند بار نیازه تست بشن به خاطر نوسان اینترنت.

***🗂️***
 تمام فایل های پروژه -  findns — اسکنر DNS Resolver برای تانل
***🔥***
نسخه v0.1.4 — تغییرات:
رفع باگ:
• رفع مشکل tunnel check (resolve/tunnel و doh/resolve/tunnel) که روی subdomain delegation همه resolverها فیل می‌شد
• رفع مشکل Ctrl+C که نتایج ذخیره نمی‌شد — الان نتایج جمع‌شده تا لحظه قطع ذخیره می‌شه
• رفع مشکل پیدا نشدن dnstt-client/slipstream-client وقتی کنار findns گذاشته بشه
• رفع خطای dnstt-client not found
قابلیت‌های جدید:
• پشتیبانی از CIDR — الان می‌تونید رنج آی‌پی مثل 
[185.51.200.0/24](http://185.51.200.0/24)
 رو مستقیم به عنوان ورودی بدید و خودکار باز می‌شه
• فلگ --proxy-auth برای پروکسی SOCKS با احراز هویت در تست‌های e2e
لینک:
[https://github.com/SamNet-dev/findns](https://github.com/SamNet-dev/findns)
