### 🕒 2026-11-16 12:48:09 UTC
**🌐 5 ابزار اپن‌سورس برای تعامل AI Agentها با وب:**
برای اینکه AI Agentها بتونن صفحات وب رو بخونن، با سایت‌ها تعامل کنن و وظایف مختلفی رو در مرورگر انجام بدن، پروژه‌های متنوعی توسعه داده شده
***👇🏻***
***1️⃣***
Kitesurf :
موتور مرورگر کلودفلر که برای اجرای وظایف وب توسط AI Agentها طراحی شده. بدون اجرای Chromium، صفحات وب رو پردازش و رندر می‌کنه و با هدف اجرای سبکتر و مقیاس‌پذیرتر توسعه پیدا کرده. 
***🔗***
[https://kitesurf.dev/](https://kitesurf.dev/)
***🔗***
 GitHub: 
[https://github.com/cloudflare/kitesurf](https://github.com/cloudflare/kitesurf)
***2️⃣***
Playwright MCP :
سرور MCP رسمی مایکروسافت برای کنترل مرورگر توسط Agentهایی مثل Claude Code و Codex.
***🔗***
 
[https://github.com/microsoft/playwright-mcp](https://github.com/microsoft/playwright-mcp)
***3️⃣***
Chrome DevTools MCP :
پروژه رسمی Chrome DevTools برای اتصال AI Agentها به مرورگر کروم و دسترسی به ابزارهای توسعه‌دهنده.
***🔗***
 
[https://github.com/ChromeDevTools/chrome-devtools-mcp](https://github.com/ChromeDevTools/chrome-devtools-mcp)
***4️⃣***
Browser Use :
یک فریم‌ورک اپن‌سورس برای ساخت AI Browser Agent. میتونید تسک موردنظرت رو با زبان طبیعی تعریف کنی تا Agent با کمک مدل هوش مصنوعی، مراحل لازم رو در مرورگر اجرا کنه.
***🔗***
 وب‌سایت :
 
[https://browser-use.com/](https://browser-use.com/)
***🔗***
 گیت‌هاب: 
[https://github.com/browser-use/browser-use](https://github.com/browser-use/browser-use)
***5️⃣***
Stagehand :
فریم‌ورک اپن‌سورس Browserbase برای ساخت و توسعه Agentهای مرورگر. با سه قابلیت اصلی میتونه دستورات متنی رو به تعامل واقعی با وبسایت تبدیل کنه.
-Act: انجام عملیات مثل کلیک و پرکردن فرم
-Observe : شناسایی عناصر و اقدامات قابل انجام در صفحه
-Extract: استخراج اطلاعات از صفحات وب
***🔗***
 GitHub : 
[https://github.com/browserbase/stagehand](https://github.com/browserbase/stagehand)
