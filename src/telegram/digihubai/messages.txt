**ابزارهای کاربردی برای تست و عیب‌‌یابی اینترنت**
 :
***1️⃣***
Globalping :
یکی از بهترین ابزارها برای بررسی یک سایت از نقاط مختلف دنیا، میتونی یک دامنه یا آیپی رو وارد کنی و از کشورهای مختلف، پینگ، Traceroute، DNS، MTR و HTTP بگیری.
***🔗***
 
[https://globalping.io](https://globalping.io/)
﻿
***2️⃣***
RIPE Atlas :
یک شبکه جهانی با بیش از 14000 Probe برای اندازه‌گیری وضعیت اینترنت.
[https://atlas.ripe.net](https://atlas.ripe.net/)
***3️⃣***
M-Lab :
مجموعه‌ای از ابزارهای تحقیقاتی برای بررسی کیفیت واقعی اینترنت.
***🔗***
 
[https://www.measurementlab.net](https://www.measurementlab.net/)
﻿
***4️⃣***
Cloudflare Radar :
برای بررسی وضعیت اینترنت در کشورهای مختلف. میتونی اطلاعاتی درباره latency کیفیت اتصال، DNS و وضعیت شبکه‌ها ببینی و متوجه بشی مشکل فقط مربوط به اتصال خودته یا در یک کشور، یا اپراتور گسترده‌تر اتفاق افتاده.
***🔗***
 
[https://radar.cloudflare.com/quality](https://radar.cloudflare.com/quality)
***5️⃣***
DNSPerf :
اگر بعضی سایت‌ها دیر باز می‌شوند، ممکن است مشکل از Dns باشد. DNSPerf عملکرد DNS Resolverهای مختلف را از نقاط مختلف جهان مقایسه میکنه تا ببینی کدوم dns سریعتر و پایدارتره.
***🔗***
 
[https://www.dnsperf.com](https://www.dnsperf.com/)
***6️⃣***
DNSViz :
ساختار dns یک دامنه را بررسی میکنه و مشکلات مربوط به dns و DNSSEC رو به شکل تصویری نشون میده.
***🔗***
 
[https://dnsviz.net](https://dnsviz.net/)
***7️⃣***
BGP.Tools :
برای زمانی که میخوای بفهمی یک آیپی یا شبکه از چه مسیری در اینترنت قابل دسترسیه. میتونی IP، Prefix یا ASN را جستجو کنی و اطلاعات مربوط به BGP و مسیرهای شبکه رو ببینی.
***🔗***
 
[https://bgp.tools](https://bgp.tools/)
***8⃣***
RIPEstat :
یک داشبورد جامع برای بررسی اطلاعات مربوط به IP، ASN، Routing و شبکه‌ها.
***🔗***
 
[https://stat.ripe.net/](https://stat.ripe.net/)
