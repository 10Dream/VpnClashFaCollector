***⭐***
***🔴***
 بررسی‌کننده دامنه Domain Checker
بررسی دسترسی دامنه‌های پربازدید یا دامنه‌های دلخواه

***🔴***
شکارچی دی‌ان‌اس DNS Hunter

***🔴***
 بررسی‌کننده IPهای Edge
اسکن برای یافتن Edge IP های قابل‌دسترس.
***🔴***
ویرایشگر کانفیگ VLESS
آدرس IP داخل کانفیگ را با IPهای دیگر از یک لیست یا رنج IP جایگزین می‌کند و خروجی را به‌صورت چند کانفیگ VLESS جدید برمی‌گرداند.
***🔴***
اسکنر CDN با Xray
رنج‌های IP مربوط به CDN را با استفاده از Xray core و کانفیگ JSON دلخواه شما اسکن می‌کند.
