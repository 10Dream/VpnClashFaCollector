***🚀***
 آموزش: دانلود مستقیم فایل و یوتیوب در گیت‌هاب (بدون نیاز به سرور و VPN!)
رفقا سلام! 
***✋***
 
امروز یه ابزار اوپن‌سورس و به‌شدت خفن به اسم Sandbox براتون پیدا کردیم.
[https://github.com/nscl5/sandbox](https://github.com/nscl5/sandbox)
این ابزار با استفاده از سیستم GitHub Actions به شما اجازه می‌ده فایل‌های اینترنتی و ویدیوهای یوتیوب رو با سرعت سرورهای خود گیت‌هاب دانلود کرده و مستقیم تو اکانت گیت‌هاب خودتون ذخیره کنید! بعدش می‌تونید فایل‌ها رو با اینترنت داخلی، بالاترین سرعت و بدون فیلترشکن دانلود کنید.
***🔥***
 چه چیزهایی رو می‌تونه دانلود کنه؟
• ویدیوهای یوتیوب (با قابلیت دور زدن محدودیت‌ها از طریق Cookie)
• لینک‌های مستقیم فایل از هر سایتی
• لینک‌های گیت‌هاب ریلیز (GitHub Releases) و Bunkr
• لینک‌های تبدیل فایل به لینکِ ربات‌های تلگرامی
(حتی می‌تونید چند تا لینک رو همزمان با فاصله، کاما یا اینتر بهش بدید تا همه رو با هم دانلود کنه)
***🛠***
 آموزش راه‌اندازی اولیه (فقط یک‌بار)
***1️⃣***
 اول وارد گیت‌هاب بشید و پروژه nscl5/sandbox رو Fork کنید تا یه کپی ازش تو اکانتتون ساخته بشه.
***2️⃣***
 تو ریپازیتوری خودتون، به تب Settings برید → Actions → General
***3️⃣***
 در بخش Workflow permissions، گزینه Read and write permissions رو انتخاب و Save کنید.
***4️⃣***
 حالا به تب Actions برید و روی دکمه سبز رنگِ «I understand my workflows, go ahead and enable them» کلیک کنید.
***🍪***
 مرحله دوم (اختیاری اما خیلی مهم): تنظیم کوکی یوتیوب
برای اینکه یوتیوب جلوی دانلودها رو نگیره:
***1️⃣***
 افزونه Get cookies.txt LOCALLY رو روی مرورگرتون نصب کنید. وارد یوتیوب بشید (ترجیحاً با اکانت فرعی) و کوکی‌ها رو Export کنید و کل متنش رو کپی کنید.
***2️⃣***
 تو گیت‌هابتون به مسیر Settings ➔ Secrets and variables ➔ Actions برید.
***3️⃣***
 روی New repository secret کلیک کنید. Name رو بنویسید: YOUTUBE_COOKIES و کل متن کوکی رو پیست کنید و Add بزنید.
***📥***
 چطور فایل دانلود کنیم؟
***1️⃣***
 به تب Actions برید و ورک‌فلوی 
***📥***
 0x00 dl رو انتخاب کنید.
***2️⃣***
 روی Run workflow کلیک کنید.
***3️⃣***
 لینک یا لینک‌های دانلودی رو پیست کنید.
(برای یوتیوب کیفیت رو روی 480p یا 720p بذارید تا حجمش زیاد نشه + حتی می‌تونید روی فایل پسورد هم بذارید)
***4️⃣***
 روی Run workflow کلیک کنید و منتظر تیک سبز 
***✅***
 بمونید.
***📂***
 فایل‌ها رو از کجا برداریم؟
سریع‌ترین راه: فایل 
***#️⃣***
 
[Links.md](http://Links.md/)
 رو تو تب Code باز کنید. تمام لینک‌های دانلود مستقیم فایل‌هاتون اونجا لیست شدن!
***🤖***
 ربات تلگرامی (راحت‌ترین روش)
توسعه‌دهنده‌ای به اسم Arshia Complus یه ربات تلگرامی هم ساخته (
[@RGitUpBot](https://t.me/RGitUpBot)
) که دیگه نیازی به باز کردن گیت‌هاب نیست:
***1️⃣***
 ربات رو استارت کنید.
***2️⃣***
 تو گیت‌هاب برید به Settings ➔ Developer settings ➔ Personal access tokens ➔ Tokens (classic) و یه توکن جدید با دسترسی repo بسازید و کپی کنید.
***3️⃣***
 تو ربات دستور /set_token YOUR_TOKEN رو بزنید.
***4️⃣***
 با دستور /set_repo username/sandbox (جای username اسم اکانت گیت‌هابتون) ریپو رو ثبت کنید.
***✅***
 حالا فقط لینک بفرستید، خودش دانلود می‌کنه!
***⚠️***
 نکات بسیار مهم:
***🔹***
 گیت‌هاب محدودیت ۱۰۰ مگابایت برای هر فایل داره. فایل‌های بزرگتر خودکار به پارت‌های زیپ کوچیک‌تر تقسیم می‌شن که با WinRAR (ویندوز) یا MiXplorer (اندروید) می‌تونید به هم بچسبونید.
***🔹***
 هر چند وقت یک‌بار پوشه dl رو خالی کنید تا سرعت شروع دانلودها تو دفعات بعدی کم نشه.
