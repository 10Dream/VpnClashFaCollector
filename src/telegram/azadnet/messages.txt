***🔴***
 
**فیلترشکن Open Source سیمُرغ (SIMORGH)**
  یک کلاینت VPN اندرویدی مبتنی بر Xray و NipoVPN است که برای شرایط عادی اینترنت، محدودیت‌های شدید و حتی اختلال اینترنت بین‌الملل طراحی شده است.
***🔸***
**این برنامه سه بخش اصلی دارد:**
***1⃣***
 
**Simple**
برای اتصال سریع با کانفیگ‌های Xray
***2⃣***
 
**Advance**
برای اسکن IP و ایجاد مسیرهای ارتباطی در شرایط محدودیت یا قطعی اینترنت
***3⃣***
 
**NipoVPN**
برای استفاده از پروفایل‌های
nipovpn://
  در بخش Simple کانفیگ‌ها به‌صورت خودکار دریافت، تست و به بهترین سرور متصل می‌شوند.
  بخش Advance از موتور RKh-MSP، اسکن IP، انتخاب SNI و حالت‌های Proxy و VPN استفاده می‌کند و امکان یافتن IPهای سالم را فراهم می‌سازد.
  برنامه علاوه بر حالت VPN، از پروکسی محلی SOCKS5 و HTTP نیز پشتیبانی می‌کند.
  قابلیت CF Config برای جایگزینی IP در کانفیگ‌های VLESS WS TLS مبتنی بر Cloudflare وجود دارد. IPهای سالم در بخشی به نام IP Memory ذخیره و برای اتصال‌های بعدی استفاده می‌شوند.
  همچنین نمایش سرعت لحظه‌ای، تست پینگ واقعی Xray، دکمه Next Healthy و ابزارهای پایداری اتصال در آن تعبیه شده است.
