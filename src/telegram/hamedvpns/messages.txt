---
***🛠***
 مرحله 1: ساخت ایمیل فیک
***🔹***
 وارد سایت Atomic Mail بشید، یه نام و رمز دلخواه بزنید (یا از ربات پسورد بگیرید)، کپچا رو حل کنید و اکانت رو بسازید. ایمیل رو کپی کنید ولی این صفحه رو نبندید چون کد تایید به این‌باکسش میاد.
***🛠***
 مرحله 2: ساخت اکانت گیتهاب
***🔹***
 وارد GitHub بشید و Sign up کنید. با همون ایمیل فیک ثبت‌نام کنید. کد تاییدی که به سایت Atomic Mail اومده رو بردارید و توی گیتهاب بزنید تا وریفای بشه.
***🔹***
 حالا وارد لینک سورس پنل (بالا گذاشتم) بشید و طبق فیلم پروژه رو Star و Fork کنید.
***🛠***
 مرحله 3: ساخت پروژه در Railway
***🔹***
 وارد سایت Railway بشید و دکمه Deploy رو بزنید.
***🔹***
 دکمه سبز Authorize رو بزنید تا به گیتهاب وصل بشه. تیک قوانین (I agree) رو بزنید و در بخش بعدی گزینه I will not deploy را انتخاب کنید.
***🔹***
 روی GitHub repository بزنید، بعد Install GitHub app رو انتخاب کنید. مطمئن بشید روی All repositories تنظیم باشه و دکمه سبز Install & Authorize رو بزنید.
***🔹***
 حالا دوباره بزنید روی New و بعد GitHub repository و پروژه‌ای که فورک کردید رو انتخاب کنید تا شروع به ساخت کنه.
***🛠***
 مرحله 4: تنظیمات نهایی پنل
***🔹***
 وقتی وضعیت پروژه Active یا Online شد، روش بزنید و برید بخش Settings.
***🔹***
 بیایید پایین در بخش Networking دکمه Generate domain رو بزنید (پورت حتماً روی 8080 باشه).
***🔹***
 کمی پایین‌تر در بخش Scale و زیربخش regions، لوکیشن رو بذارید روی Netherlands (هلند) که سرعتش بهتره.
***🔹***
 حالا از بالای صفحه دکمه بنفش Deploy رو بزنید تا تغییرات ذخیره بشن. پس از اتمام، آدرس پنل (که آخرش app. داره) رو باز کنید و آخرش عبارت /login رو اضافه کنید تا صفحه ورود بیاد. (رمز دیفالت: 123456)
