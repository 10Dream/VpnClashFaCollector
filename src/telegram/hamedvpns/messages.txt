### 🕒 2026-04-06 08:13:19 UTC
ارسال به روبیکا ممنوع 
***🙏***
***❤️***
آموزش اتصال سایفون (Psiphon) با V2Ray
***✔️***
***1️⃣***
 وارد V2Ray شوید → سه نقطه بالا → Settings.
***2️⃣***
 گزینه Local Proxy Port را روی 10808 بگذارید و Mode را روی Proxy Only تنظیم کنید.
***3️⃣***
 به صفحه اصلی برگردید و یک کانفیگ را روشن کنید.
***4️⃣***
 وارد Psiphon شوید → VPN Settings.
***5️⃣***
 گزینه Don't tunnel selected apps را فعال کنید.
***6️⃣***
 در Select Apps تمام برنامه‌های ایرانی + V2Ray را تیک بزنید.
***💡***
 برای سرعت بهتر، پیشنهاد می‌شود همه برنامه‌ها به‌جز تلگرام تیک بخورند.
***7️⃣***
 وارد Proxy Settings شوید:
Connect through an HTTP proxy فعال
Use the following settings فعال
مشخصات:
Host: 127.0.0.1
Port: 10808
***8️⃣***
 به صفحه اصلی سایفون برگردید و Start را بزنید.
اگر تا ۳۰ ثانیه وصل نشد، در V2Ray یک کانفیگ دیگر را امتحان کنید.
نکته: پینگ ندادن کانفیگ در V2Ray به معنی وصل نشدن سایفون نیست؛ اگر شک داشتید چند کانفیگ را تست کنید.
